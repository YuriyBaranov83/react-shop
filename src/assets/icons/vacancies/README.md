# Vacancies Icons

Place vacancy page icons in this folder.

Recommended filenames (match `iconName` in `vacanciesData.js`):
- `cashier.svg`
- `bike-courier.svg`
- `seller.svg`
- `hall-manager.svg`
- `call-center-operator.svg`
- `senior-cashier.svg`
- `loader.svg`
- `accountant.svg`

Supported formats: `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`.
