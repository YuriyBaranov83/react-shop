# AGENTS.md

## Главные правила

- Перед любой задачей сначала прочитать этот файл.
- Работать только в рамках поставленной задачи.
- Не делать лишний рефакторинг по своей инициативе.
- Не менять несвязанные файлы.
- Не переписывать рабочий код, если задача этого не требует.
- Если найден unrelated bug — сообщить отдельно, но не исправлять без разрешения.
- Держать изменения маленькими и понятными.

## Контент и локализация

- Не добавлять статичный текст на русском языке в пользовательский интерфейс.
- Это касается JSX, data-файлов, `alt`, `title`, `aria-label`, `placeholder`, meta-текстов и любых других строк, видимых пользователю.
- Не добавлять в проект российский контекст: адреса, города, телефоны, домены, валюту `RUB`, символ `₽`, обозначения `руб.`, российские организации и любые другие привязки к РФ.
- Если нужен новый статичный текст и язык не указан, использовать украинский.
- Если найден существующий русский текст или российский контекст вне текущей задачи — сообщить отдельно, но не исправлять без разрешения.

## CSS и классы

- В проекте используются CSS Modules.
- Не переименовывать CSS-классы без необходимости.
- Не переводить существующие классы из kebab-case в camelCase.
- Если в CSS есть класс `.section-title`, использовать его так:

  ```jsx
  className={styles["section-title"]}
  ```

- Не менять его на:

  ```jsx
  className={styles.sectionTitle}
  ```

- Если класс нужно переименовать, менять одновременно и JSX, и CSS.
- Не переносить локальные стили в globals.css.
- Не писать inline styles без необходимости.
- Использовать существующие CSS variables/tokens, если они уже есть в проекте.

## Компоненты

- Перед созданием нового компонента сначала проверить, нет ли уже похожего.
- Переиспользовать существующие компоненты, если они подходят.
- Не создавать дубли компонентов.
- Если одинаковая разметка повторяется 2+ раза — вынести в компонент.
- Не делать один огромный компонент.
- Повторяющиеся списки/карточки выносить в data-файлы.
- Не хардкодить большие массивы прямо в JSX.

## JSX / React

- Не использовать key={index}, если есть стабильный id.
- Не добавлять новые зависимости без разрешения.
- Не менять роутинг без задачи.
- Не придумывать новые страницы, если их не просили.
- Не оставлять href="#" или href="".
- Использовать <a> только для реальной навигации.
- Использовать <button> для действий.

## Accessibility

- У кнопок должен быть понятный текст или aria-label.
- У изображений должен быть alt, если они не декоративные.
- Декоративные иконки делать aria-hidden="true".
- Модальные окна должны иметь role="dialog", aria-modal="true", aria-labelledby.
- Модалки должны закрываться по Esc и кнопке закрытия.
- Не убирать видимый focus state.

## Workflow

Перед началом реализации:

1. Прочитать AGENTS.md.
2. Изучить только релевантные файлы.
3. Коротко написать план.
4. Потом делать минимальные изменения.

После реализации:

1. Запустить npm run lint.
2. Запустить npm run build.
3. В ответе написать:
   - какие файлы изменены;
   - что сделано;
   - какие проверки запускались;
   - остались ли риски.

После создания AGENTS.md ничего больше не меняй.
