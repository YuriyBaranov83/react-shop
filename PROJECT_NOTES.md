## Текущий срез проекта

- Проект: React/Vite интернет-магазин.
- Страницы: `home`, `catalog`, `cart`, `favorites`, `contacts`, `vacancies`, `not-found`.
- Основные слои: `components`, `features`, `pages`, `data`, `styles`.
- Features: `auth`, `cart`, `favorites`.
- Общие стили: `src/styles/tokens.css`, `reset.css`, `globals.css`, `fonts.css`.
- Локальные стили компонентов оформлены через CSS Modules рядом с JSX.
